# 模板动态发现策略（template-discovery）

本文件规定 `lzhit-teaching-archive` 技能如何**动态发现并解析**用户提供的模板目录，**不依赖任何硬编码的模板内容**。模板随学期/学院变化时，只需用户更换模板目录，技能自动适配。

> 配套原则见 `business-rules.md` 第四节"模板读取策略"。

---

## 一、模板根目录的典型组织（参考，非强制）

柳州工学院等高校的模板根目录常按编号子目录组织：

```
模板根目录/
├── 1.理论课考试材料模板及要求/
│   ├── 1.（正常班级学生-正考）试卷材料归档确认单.xlsx   ← 校验依据
│   ├── 2.（重修补修学生-正考）试卷材料归档确认单.xlsx   ← 校验依据（备选）
│   ├── 取消课程考核资格审查表.doc
│   ├── 模板（理论课考试）/                              ← 附件模板子目录
│   │   ├── 附件1-1：命题计划表（...）.xlsx
│   │   ├── 附件1-2：样卷（...）.doc
│   │   ├── 附件3：过程考核成绩登记表（...）.xls
│   │   ├── 附件4：成绩登记表（...）.xls
│   │   ├── 附件5-1：试卷分析报告（...）.doc
│   │   ├── 附件6-1：客观题阅卷规范（...）.jpg          ← 图片，跳过
│   │   ├── 附件9：补考名单（...）.xls
│   │   └── ...
│   └── ！！！！！！（务必仔细阅读）考试要求及材料提交要求.doc  ← 校验依据
├── 2.理论课考查材料模板及要求/
├── 3.课内实验、课内上机、课内实践材料模板及要求/
├── 4.课程设计材料模板及要求/
├── 5.实训材料模板及要求/
├── 6.实习材料模板及要求/
└── 7.补考/
    └── 3.（所有学生-补考）试卷材料归档确认单.xlsx
```

> 上述结构仅为示例。技能不假定固定编号或固定名称，按"关键词匹配 + 目录角色识别"动态解析。

## 二、课程类型与子目录匹配

扫描模板根目录下的一级子目录，按子目录名关键词匹配课程类型：

| 课程类型 | 子目录名需包含的关键词（任一组合命中） |
|----------|----------------------------------------|
| T1 理论课（考试） | "理论课" + "考试" |
| T2 理论课（考查） | "理论课" + "考查" |
| T3 课程设计 | "课程设计" |
| T4 实训 | "实训" |
| T5 实习 | "实习" |
| L1 课内实验 | "课内实验" 或 "课内上机" 或 "课内实践" 或 "实验"+"课内" |
| 补考 | "补考" |

匹配规则：
- T1/T2 都含"理论课"，须再用"考试/考查"区分。
- L1 关键词较宽泛，须避免与 T3/T4/T5 混淆（T3/T4/T5 子目录名通常不含"课内"）。
- 一个子目录可能同时匹配多个类型（如"课内实验"含"实验"），按上表精确匹配优先。
- 若多个子目录匹配同一类型，向用户确认使用哪个。
- 若无子目录匹配识别出的课程类型，提示用户补充对应模板。

## 三、子目录内角色识别

进入匹配的课程类型子目录后，识别三类角色文件：

### 3.1 归档确认单（校验依据）

- 识别条件：文件名含"归档确认单"，扩展名为 `.xlsx`。
- 可能有多个版本（正常班级正考/重修补修/补考），按场景选择：
  - 正考场景：选"正常班级"+"正考"版本。
  - 重修补修场景：选"重修补修"版本。
  - 补考场景：选"补考"版本（在 `7.补考` 目录下）。
- 解析：读取"袋内资料"表，提取 `序号 | 归档材料 | 规范要求`，作为材料完整性与规范要求校验基准（详见 `validation-rules.md`）。

### 3.2 要求及材料提交要求文件（校验依据补充）

- 识别条件：文件名含"要求"且含"提交"（如"考试要求及材料提交要求.doc"），或文件名以"！！！！"开头。
- 解析：若为 `.docx` 直接读文本；若为 `.doc`（老格式）尝试读取，失败则注明"未自动解析，请人工参照"。
- 作用：作为归档确认单之外的补充规范说明。

### 3.3 附件模板（生成依据）

- 识别条件：位于"模板（XXX）"子目录下，或文件名以"附件"开头。
- 文件名解析格式：`附件N[-N]：材料名（要求说明）.扩展名`
  - 解析出：附件编号、材料名、要求说明、扩展名。
  - 例：`附件3：过程考核成绩登记表（正常学生1个行政班1个表，重修补修学生汇总1个表）.xls`
    → 编号 3，材料名"过程考核成绩登记表"，要求说明"正常学生1个行政班1个表..."，扩展名 .xls
- 材料名用于匹配 `business-rules.md` 的处理边界（如"命题计划表"→不生成）。

## 四、文件过滤规则

扫描子目录与附件模板时，按以下规则过滤：

| 文件特征 | 处理 |
|----------|------|
| `~$` 开头 | 忽略（Office 锁文件） |
| 扩展名 `.jpg/.jpeg/.png/.gif/.bmp` | 跳过不解析（图片示例），归档清单标注"图片示例（未解析）" |
| 扩展名 `.doc`（老格式） | 尝试读取，失败注明"未自动解析" |
| 扩展名 `.docx/.xlsx/.xls` | 正常解析 |
| 扩展名 `.pdf` | 尝试文本层提取 |
| 隐藏文件/系统文件 | 忽略 |

## 五、模板缺失时的兜底

- 若某课程类型子目录不存在：提示用户补充该类型模板，技能不阻塞，相关材料标记"待补充模板"。
- 若归档确认单缺失：校验报告注明"未找到归档确认单，材料完整性校验降级为内置基础清单"。
- 若附件模板缺失：该材料生成"待补充"占位，清单标记"待补充模板"。
- 若要求文件缺失：仅影响规范说明，不影响生成。

---

## 六、模板版本管理建议

- 用户每学期更换新模板目录时，建议保留旧版本备份。
- 模板根目录名建议含学期与日期（如"（25-26-2学期）课程考核+实践材料模板及要求20260312"），便于追溯。
- 技能运行时记录所用模板目录路径与文件清单到归档清单，便于审计。
