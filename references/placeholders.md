# 占位符字段对照表

本文件列出 `lzhit-teaching-archive` 技能所有可用占位符。模板内用双花括号包裹字段名（如 `{{课程名}}`），引擎按课程信息自动替换。

> 占位符必须完整位于**同一个文本片段**内，不要跨多个格式块拆分。

## 一、基础信息占位符

| 占位符 | 含义 | 来源 | 必需 |
|--------|------|------|------|
| `{{课程名}}` | 课程名称 | 用户提供 | 是 |
| `{{课程代码}}` | 课程代码 | 用户提供 | 是 |
| `{{学期}}` | 学期，如 `2025-2026-2` | 用户提供 | 是 |
| `{{学年}}` | 学年，如 `2025-2026` | 由学期派生 | 否 |
| `{{教师}}` | 任课教师姓名 | 用户提供 | 是 |
| `{{班级}}` | 班级名称 | 用户提供 | 是 |
| `{{学院}}` | 所属学院 | 用户提供 | 否 |
| `{{专业}}` | 所属专业 | 用户提供 | 否 |
| `{{日期}}` | 当前日期（YYYY-MM-DD） | 系统生成 | 否 |

## 二、课程类型占位符

| 占位符 | 含义 | 来源 |
|--------|------|------|
| `{{课程类型}}` | 课程类型中文名，如「理论课（考试）」 | 大纲识别 |
| `{{课程类型代码}}` | 课程类型代码，如 `theory_exam` | 大纲识别 |
| `{{考核方式}}` | 考核方式描述，如「闭卷考试」「大作业」 | 大纲识别 |
| `{{是否含课内实验}}` | 是/否 | 大纲识别 |

## 三、成绩相关占位符

| 占位符 | 含义 | 来源 |
|--------|------|------|
| `{{学生人数}}` | 选课学生人数 | 教学过程数据 |
| `{{及格率}}` | 及格率（百分比） | 成绩数据计算 |
| `{{优秀率}}` | 优秀率（百分比） | 成绩数据计算 |
| `{{平均分}}` | 班级平均分 | 成绩数据计算 |
| `{{最高分}}` | 最高分 | 成绩数据计算 |
| `{{最低分}}` | 最低分 | 成绩数据计算 |
| `{{平时权重}}` | 平时成绩权重（如 40） | 配置 |
| `{{期末权重}}` | 期末成绩权重（如 60） | 配置 |

## 四、教学总结类占位符

| 占位符 | 含义 | 来源 |
|--------|------|------|
| `{{教学总结}}` | 教学总结正文（由教师填写或AI辅助生成） | 用户提供/AI生成 |
| `{{改进建议}}` | 教学改进建议 | 专家分析生成 |

## 五、未命中占位符处理

- 若模板中的占位符在课程信息中找不到对应值，引擎**保留原占位符**不替换。
- 在归档清单与校验报告中标记「未命中占位符」，提示用户补充对应字段。
- 详见 `validation-rules.md` 校验项 4.1。

## 六、自定义占位符

用户可在配置 JSON 的 `course` 字段中添加任意自定义键值对，模板中用对应 `{{键名}}` 引用即可。例如：

```json
{
  "course": {
    "课程名": "高等数学",
    "学期": "2025-2026-2",
    "教师": "张老师",
    "班级": "计科2301",
    "开课单位": "数学学院"   // 自定义
  }
}
```

模板中：`开课单位：{{开课单位}}` → `开课单位：数学学院`
