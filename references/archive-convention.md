# 归档规范与模板匹配说明

本文件是 `lzhit-teaching-archive` 技能的归档规范与模板匹配规则说明。脚本 `scripts/build_archive.py` 据此组织输出目录、匹配模板、命名文件。

## 一、模板组织结构

用户提供模板时，建议按**课程类型分子文件夹**存放。模板根目录结构示例：

```
templates/                      ← 模板根目录（用户指定或默认 assets/templates/）
├── 理论课（考试）/            ← T1
│   ├── 教学大纲.docx
│   ├── 期末试卷A.docx
│   ├── 期末试卷B.docx
│   ├── 参考答案与评分标准.docx
│   ├── 命题审批表.docx
│   ├── 试卷分析表.docx
│   ├── 成绩登记表.xlsx
│   ├── 平时成绩表.xlsx
│   ├── 考勤表.xlsx
│   └── 课程总结.docx
├── 理论课（考查）/            ← T2
│   └── ...
├── 课程设计/                  ← T3
│   └── ...
├── 实训/                      ← T4
│   └── ...
├── 实习/                      ← T5
│   └── ...
└── 课内实验/                  ← L1（附加）
    └── ...
```

> 用户也可不分子文件夹，把所有模板放在根目录，但此时模板文件名需包含课程类型关键词以便匹配。

## 二、模板匹配策略

技能识别出课程类型后，需在模板根目录中找出**正确**的子文件夹。匹配依据优先级：

### 优先级 1：子文件夹名匹配

子文件夹名包含课程类型关键词即匹配。关键词对照：

| 类型代码 | 子文件夹名关键词（任一命中即可） |
|----------|----------------------------------|
| T1 theory_exam | 理论课、考试 |
| T2 theory_assess | 理论课、考查 |
| T3 course_design | 课程设计、设计 |
| T4 training | 实训 |
| T5 internship | 实习 |
| L1 lab | 课内实验、实验、上机、实践 |

> 注意：T1 与 T2 都含「理论课」关键词，需进一步用「考试 / 考查」区分。匹配时优先精确匹配（子文件夹名同时含「理论课」+「考试」），其次模糊匹配（仅含「考试」）。

### 优先级 2：模板文件名匹配

若无匹配子文件夹，扫描根目录下所有模板文件，文件名包含课程类型关键词即归入该类型。

### 优先级 3：多候选向用户确认

若有多个候选子文件夹/文件均匹配，向用户列出候选并请其确认。

### 优先级 4：未找到匹配

提示用户提供对应课程类型的模板，并在归档清单中将该类型材料标记为「待补充」。

## 三、输出目录结构

输出根目录命名：

```
{课程名}_{学期}_课程归档/
```

例如：`高等数学_2025-2026-2_课程归档/`

目录树（默认，按课程类型裁剪）：

```
{课程名}_{学期}_课程归档/
├── 01_教学文件/
│   ├── 教学大纲_{课程名}_{学期}.docx
│   ├── 教学日历_{课程名}_{学期}.docx
│   └── 教材信息表_{课程名}_{学期}.xlsx
├── 02_考核材料/          ← 按课程类型填充不同内容
│   ├── （T1/T2）试卷A/B、参考答案、命题审批表、试卷分析
│   ├── （T3）设计任务书、设计报告、答辩记录
│   ├── （T4）实训任务书、实训报告、操作考核记录
│   └── （T5）实习计划、实习日志、实习鉴定表
├── 03_成绩与考勤/
│   ├── 成绩登记表_{课程名}_{学期}.xlsx
│   ├── 平时成绩表_{课程名}_{学期}.xlsx
│   └── 考勤表_{课程名}_{学期}.xlsx
├── 04_学生成果/
│   └── 作业/报告/设计样例（复制用户提供）
├── 05_课内实验/           ← 仅当 need_lab_archive=true 时生成
│   └── 实验报告、实验成绩表等
├── 06_教学总结/
│   ├── 课程总结_{课程名}_{学期}.docx
│   └── 教学反思_{课程名}_{学期}.docx
├── 规范性校验报告.md       ← 自动生成
├── 教学专家分析报告.md     ← 自动生成
├── 归档清单.md
└── 归档清单.csv
```

> 「02_考核材料」的具体内容由课程类型决定，详见 `course-type-rules.md` 第八节（待补充）。

## 四、文件命名规则

```
{材料名}_{课程名}_{学期}.{ext}
```

例如：`教学大纲_高等数学_2025-2026-2.docx`

数据驱动文档（成绩表、考勤表）不需模板，由教学过程数据生成。

## 五、可用占位符

模板内用双花括号包裹字段，引擎按课程信息替换。完整清单见 `placeholders.md`，常用：

```
{{课程名}} {{课程代码}} {{学期}} {{学年}} {{教师}} {{班级}} {{学院}} {{专业}} {{日期}}
```

> 占位符必须完整位于**同一个文本片段**内，不要跨多个格式块拆分。

## 六、材料生成方式（kind）

每份材料在规范中标注 `kind`：

| kind | 含义 | 处理方式 |
|------|------|----------|
| template | 填占位符生成 | 读模板 → 替换 `{{字段}}` → 输出 |
| copy | 原样复制 | 直接复制用户提供的文件（如 PPT/PDF 样例） |
| data | 数据驱动生成 | 由教学过程数据生成表格（成绩表、考勤表） |

## 七、成绩权重

默认总评权重：平时 40% + 期中 0% + 期末 60%。可在配置 JSON 的 `data.weights` 中覆盖。

若数据中已有 `总评` 列，直接使用，不再计算。

## 八、输出附注

每份由引擎生成的材料末尾追加：

> 本材料由AI辅助生成，仅供参考，请认真核对后由相关负责人签字确认。

- `copy` 类材料（原样复制的样例）不追加附注。
- `data` 类材料（数据表）在表格下方追加附注行。
- `template` 类材料在文档末尾追加附注段落。

## 九、自定义学院规范

若用户的学院有专属归档规范：

1. 编辑本文件对应小节，调整输出目录结构与材料清单。
2. 或在配置 JSON 中指定 `convention` 覆盖路径，引用自定义规范文件。
3. 调整成绩权重、文件命名规则等。

改完保存，重新运行 `scripts/build_archive.py` 即可生效。
