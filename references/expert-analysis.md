# 高校教学专家分析框架

本文件是 `lzhit-teaching-archive` 技能专家分析报告的**框架说明**。脚本 `scripts/expert_report.py` 据此生成 `教学专家分析报告.md`。

技能始终以**高校教学专家**角色，对题目设计合理性、考试成绩分布、教学质量给出专业判断与建议。分析独立于归档材料，作为教学反思与质量改进参考。

## 一、专家角色定位

- 角色：高校教学督导 / 教学质量评估专家。
- 立场：客观、专业、建设性。不溢美、不苛责，以数据为依据。
- 输出：分析报告，附于归档目录根目录下，独立成文。

## 二、分析维度一：题目设计合理性

### 2.1 覆盖度分析

- 评估试卷/考核题目对大纲知识点的覆盖程度。
- 维度：
  - 章节覆盖：试卷题目涉及章节占大纲总章节的比例。
  - 知识点覆盖：题目考查的知识点占大纲核心知识点的比例。
  - 认知层次覆盖：记忆 / 理解 / 应用 / 分析 / 评价 / 创造（布鲁姆分类）的分布。
- 判断标准：
  - 覆盖度 ≥ 80%：良好。
  - 60%–80%：一般，建议补充。
  - < 60%：不足，建议调整。
- 数据来源：试卷题目（用户提供）+ 教学大纲。

### 2.2 难度分布

- 评估题目难度搭配。
- 维度：
  - 难/中/易题目分值比例（建议 3:5:2 或 2:6:2）。
  - 题型搭配（客观题 / 主观题比例，建议与课程性质匹配）。
  - 区分度：高分组与低分组答题差异。
- 判断标准：
  - 难度搭配合理，区分度良好：优秀。
  - 偏易（易题占比过高）或偏难（难题占比过高）：建议调整。

### 2.3 分值合理性

- 评估各题分值与考查内容的重要性匹配。
- 维度：
  - 核心知识点分值占比是否与大纲学时占比匹配。
  - 单题分值是否过大（建议单题不超过总分 25%）。
  - 客观题与主观题分值比例。

### 2.4 与大纲契合度

- 评估试卷是否体现大纲要求的考核目标。
- 维度：
  - 考核方式（考试/考查）与大纲一致。
  - 考核内容在大纲范围内。
  - 难度与大纲要求匹配。

## 三、分析维度二：考试成绩分布

### 3.1 描述性统计

- 均值（Mean）。
- 标准差（Std）。
- 最高分、最低分、中位数。
- 及格率（≥60 分占比）。
- 优秀率（≥85 分或 ≥90 分占比，按学校规定）。
- 不及格率。

### 3.2 分布形态

- 判断分布形态：
  - 正态分布：理想，说明题目区分度良好。
  - 偏态分布：
    - 正偏（左偏，低分多）：题目偏难或教学效果不佳。
    - 负偏（右偏，高分多）：题目偏易或学生水平较高。
  - 双峰分布：说明学生水平分化，可能存在教学分层问题。
- 判断方法：偏度（Skewness）、峰度（Kurtosis），或直方图目测。

### 3.3 异常分数识别

- 异常高分（如 ≥98 分）：确认是否真实。
- 异常低分（如 ≤20 分）：确认是否缺考或特殊原因。
- 成绩聚集（如大量学生集中在某分数段）：提示题目区分度不足。

### 3.4 与历史/同类对比（可选）

- 若用户提供历史数据，对比本次成绩与历届/同类课程的差异。
- 判断教学效果变化趋势。

## 四、分析维度三：教学质量判断

### 4.1 教学效果推断

基于成绩分布与试卷分析推断教学效果：

- 高及格率 + 正态分布 + 良好区分度：教学效果良好。
- 低及格率：提示教学或考核存在问题，需排查原因。
- 高及格率但区分度不足（成绩集中高分段）：题目偏易，未有效区分学生水平。
- 双峰分布：提示学生基础差异大，建议分层教学。

### 4.2 薄弱环节识别

- 通过各题得分率识别学生薄弱知识点。
- 得分率 < 60% 的题目对应知识点为薄弱环节。
- 建议针对性加强教学。

### 4.3 改进建议

按优先级给出建议：
- 教学重点调整（加强薄弱环节）。
- 考核方式改进（如调整难度、优化题型）。
- 教学方法优化（如增加互动、案例）。
- 学生支持（如辅导、分层教学）。

## 五、建议生成原则

- **数据为依据**：所有判断基于成绩数据与试卷分析，不空泛。
- **建设性**：建议具体可操作，避免「加强教学」等空话。
- **分层**：区分短期可改进与长期优化。
- **尊重教师**：以专业同行口吻，避免指责。
- **针对性**：针对本课程的具体情况，不复用模板化套话。

## 七、数据不足时的处理

- 缺少试卷题目：跳过题目设计分析，标注「数据不足，无法分析」。
- 缺少成绩数据：跳过成绩分布分析，标注「数据不足」。
- 仅有部分数据：基于已有数据分析，明确标注分析的数据范围与局限。
- 不臆测、不编造数据。
