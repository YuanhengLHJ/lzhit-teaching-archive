# 课程类型识别规则

本文件是 `lzhit-teaching-archive` 技能识别课程类型的**权威规则说明**。脚本 `scripts/identify_course_type.py` 据此实现。

## 一、课程类型总览

本技能区分 **5 类考核模板** + **1 类课内实验模板**，共 6 类：

| 编号 | 类型代码 | 中文名 | 模板类别 | 说明 |
|------|----------|--------|----------|------|
| T1 | theory_exam | 理论课（考试） | 考核模板 | 期末统一考试 |
| T2 | theory_assess | 理论课（考查） | 考核模板 | 大作业/报告考查 |
| T3 | course_design | 课程设计 | 考核模板 | 工科设计课 |
| T4 | training | 实训 | 考核模板 | 集中实训 |
| T5 | internship | 实习 | 考核模板 | 校外实习 |
| L1 | lab | 课内实验 | 课内实验模板 | 理论课内的实验/上机/实践环节，**附加生成** |

## 二、识别依据

识别主要依赖大纲中的两个字段：

1. **「终结性考核」一栏**：用于区分 T1 / T2 / T3 / T4 / T5。
2. **课程性质 / 教学环节描述**：用于识别 L1（课内实验）。

若大纲未明确分栏，则扫描全文关键词。

## 三、考核类型关键词

### T1 理论课（考试）

「终结性考核」一栏出现以下任一关键词即判定为 T1：

- 考试、闭卷考试、开卷考试、机试、笔试、期末考试、统一考试、笔试+机试

> **关键判定**：只要「终结性考核」栏出现「考试 / 机试 / 笔试」等类似描述，统一归为 T1，**不论是否同时存在大作业**。

### T2 理论课（考查）

「终结性考核」一栏出现以下任一关键词，**且不含 T1 关键词**时判定为 T2：

- 大作业、报告、课程报告、论文、答辩、作品、课程论文、综合报告、调研报告

> **关键判定**：若「终结性考核」栏出现「大作业 / 报告」等内容，则为 T2。若同时出现「考试」与「大作业」，**以「考试」为准**，归为 T1。

### T3 课程设计

「终结性考核」一栏或课程性质中出现：

- 课程设计、设计任务、设计报告、工程设计、综合设计

> 注意：若「终结性考核」栏明确为「课程设计」，优先归为 T3 而非 T2。

### T4 实训

「终结性考核」一栏或课程性质中出现：

- 实训、实训报告、操作考核、技能考核、集中实训

### T5 实习

「终结性考核」一栏或课程性质中出现：

- 实习、实习报告、实习鉴定、毕业实习、专业实习、顶岗实习

## 四、课内实验（L1）识别

L1 不是独立课程类型，而是**附加项**。识别规则：

- 当课程类型为 **T1 或 T2**（即理论课）时，扫描大纲是否存在以下关键词：
  - 课内实验、上机、实践、实验学时、上机学时、实践学时、实验环节
- 若存在，标记 `need_lab_archive = true`，**额外**生成课内实验归档材料。
- 若课程类型已是 T3/T4/T5（课程设计/实训/实习），**不再**叠加 L1（这类课程本身即实践类）。

## 五、识别流程

```
读取大纲全文
  │
  ├─ 提取「终结性考核」一栏内容
  │     │
  │     ├─ 含 T5 关键词（实习）       → T5 实习
  │     ├─ 含 T4 关键词（实训）       → T4 实训
  │     ├─ 含 T3 关键词（课程设计）   → T3 课程设计
  │     ├─ 含 T1 关键词（考试/机试/笔试） → T1 理论课（考试）
  │     ├─ 含 T2 关键词（大作业/报告） → T2 理论课（考查）
  │     └─ 都不含                     → 默认 T1（保守归为考试类，并向用户确认）
  │
  ├─ 若类型为 T1 或 T2：
  │     扫描全文是否含 L1 关键词 → need_lab_archive
  │
  └─ 输出 {course_type, need_lab_archive, evidence}
```

> 优先级顺序：T5 > T4 > T3 > T1 > T2。即若「终结性考核」栏同时出现「实习」与「考试」，以「实习」为准。

## 六、识别证据（evidence）

识别结果需附带证据，便于用户核对与冲突时提问：

- `matched_keywords`：命中的关键词列表。
- `source_snippet`：命中的原文片段（前后各 20 字）。
- `field`：命中的字段名（「终结性考核」/ 课程性质 / 全文）。

## 七、边界情况

- **大纲无「终结性考核」分栏**：扫描全文，按关键词命中判定。若全文无任何关键词，默认 T1 并向用户确认。
- **多类型关键词共存**：按优先级 T5 > T4 > T3 > T1 > T2 判定，并在证据中记录所有命中项，提示用户核对。
- **大纲为扫描件 PDF（无文本层）**：脚本无法直接解析，提示用户先 OCR 或提供 docx/txt 版本。
- **课程类型与用户提供模板不一致**：以大纲识别结果为准，提示用户补充对应类型模板。
