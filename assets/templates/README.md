# 模板放置指引

把你平时用的归档材料**模板**放在模板根目录下，本技能会从这里读取、按课程类型匹配、自动填充后生成归档文件。

## 一、模板根目录

模板根目录可通过配置 JSON 的 `templates_dir` 字段指定，或默认使用技能内置的 `assets/templates/`。

## 二、按课程类型分子文件夹（推荐）

建议按课程类型分子文件夹存放模板，便于技能自动匹配。子文件夹命名建议包含课程类型关键词：

```
templates/
├── 理论课（考试）/            ← T1，关键词：理论课、考试
├── 理论课（考查）/            ← T2，关键词：理论课、考查
├── 课程设计/                  ← T3，关键词：课程设计、设计
├── 实训/                      ← T4，关键词：实训
├── 实习/                      ← T5，关键词：实习
└── 课内实验/                  ← L1（附加），关键词：课内实验、实验、上机、实践
```

> 子文件夹名只要包含对应关键词即可命中，不强求完全一致。例如「理论课考试模板」「期末考试-理论课」均可匹配 T1。

### 关键词对照

| 类型 | 子文件夹名关键词（任一命中即可） |
|------|----------------------------------|
| T1 理论课（考试） | 理论课 + 考试 |
| T2 理论课（考查） | 理论课 + 考查 |
| T3 课程设计 | 课程设计、设计 |
| T4 实训 | 实训 |
| T5 实习 | 实习 |
| L1 课内实验 | 课内实验、实验、上机、实践 |

> 注意：T1 与 T2 都含「理论课」关键词，需进一步用「考试 / 考查」区分。

## 三、不分子文件夹的存放方式（可选）

若不便分子文件夹，可把所有模板放在根目录，但**模板文件名需包含课程类型关键词**以便匹配。例如：

```
templates/
├── 理论课考试-教学大纲.docx
├── 理论课考试-期末试卷A.docx
├── 课程设计-设计任务书.docx
└── ...
```

## 四、模板内占位符写法

模板里需要用到的字段写成 `{{字段名}}`，例如：

```
课程名：{{课程名}}
学期：{{学期}}
任课教师：{{教师}}
```

> 占位符必须完整位于**同一个文本片段**内，不要跨多个格式块拆分（如在 Word 中被加粗、换行拆开）。

完整占位符清单见 `references/placeholders.md`。

## 六、成绩与考勤类（不需模板）

成绩登记表、平时成绩表、考勤表等**数据驱动文档不需要模板**，由你提供的平时数据（CSV / Excel，列名用中文如 `学号`、`姓名`、`平时`、`期末`）自动生成。运行技能时把数据文件路径告诉它即可。

## 七、没有模板会怎样？

若某个材料你暂时没放模板，引擎不会报错，而是：

- 在归档目录里生成一份 `待补充_xxx.txt` 占位说明。
- 在《归档清单》中标记为「待补充」。
- 在《规范性校验报告》中标记为「待补充」并提示。

事后补填模板后重跑即可。

## 八、多模板匹配时的处理

若技能识别出课程类型后，在模板根目录下找到**多个**匹配的子文件夹或文件，会向你列出候选并请你确认使用哪一个。避免误用错误模板。
